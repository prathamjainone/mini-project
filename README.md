# Task Management Application

This is a simple Task Management project built after a 5-day Spring Boot training workshop. It includes both a backend (Spring Boot) and a frontend. The backend provides REST APIs to manage tasks, and the frontend allows users to interact with these APIs in a user-friendly way.

## Features

- Add, view, update, and delete tasks
- Separate frontend and backend
- Google Calendar API integration (coming soon)

## Tech Stack

- **Backend:** Java, Spring Boot, Spring Web, Spring Data JPA, H2 Database, MySql
- **Frontend:** React
- **Build Tool:** Maven
